- **Status:** completed
- **Theory:** fetch_all_news() currently processes 35+ RSS feeds sequentially with `time.sleep(rss_delay)` between each request. Using a ThreadPoolExecutor (max_workers=8) allows concurrent HTTP requests, drastically reducing wall-clock time. RSS parsing is CPU-light and network-bound, so parallel I/O provides near-linear speedup until the server-side rate-limit kicks in.
